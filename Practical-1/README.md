# StudentHub_2026 - Web Portal

A comprehensive, multi-page frontend web application designed as a student hub portal. This application features seamless page-to-page navigation enabling mock student lifecycle operations, account security, and dashboard visualization.

## 📁 Project Architecture & Layout

This project consists of 10 interconnected structural web pages:

### 🏠 Main Hub & Account Portals
*   **`Home Page`:** The central application dashboard containing structured navigation links pointing to all internal portal features.
*   **`Login Page`:** Secure entry interface parsing user validation requests via Username and Password fields.
*   **`Login Success Page`:** Redirect confirmation page displayed upon passing user authorization.
*   **`Forgot Password Page`:** Account recovery module containing workflows to modify or reset profile passwords.

### 📋 Student Management Modules
*   **`Attendance Page`:** Visual log tracker reporting active student presence metrics.
*   **`Assignment Page`:** Evaluation center tracking school tasks, deadlines, and project data.
*   **`Announcement Page`:** Communication board displaying global administrative posts and live updates.
*   **`Fees Page`:** Finance engine managing payment items, transaction statuses, and invoice generation.

### 🏢 Support & Information
*   **`About Us Page`:** Corporate profile page mapping the application identity and developer information.
*   **`Contact Us Page`:** Support channel facilitating user communication and message inputs.

## 🚀 Deployment & Local Execution

To review the project locally in your workspace:
1. Access your project directory using your command terminal.
2. Launch `index.html` (the Home Page) inside any modern native web browser.
3. Use the navbar layout blocks to step cleanly through the module navigation paths.
